# Generation 3 shiny animated backs

Run `python tools/import_emerald_shiny_sprites.py --root .` to import Emerald
shiny back sprites for National Dex #001-#386. Emerald supplies Deoxys Speed
Forme (`386S`), stored in the engine's species-level `deoxys.png` slot.

Generated artwork is ignored by Git and is not covered by the mod's MIT
license. Verify that you have the right to use and distribute it.
