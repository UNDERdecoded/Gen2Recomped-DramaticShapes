# Generation 2 shiny animated fronts

Crystal shiny APNGs for National Dex 001 Bulbasaur through 251 Celebi are
converted into runtime PNG atlases by:

```powershell
python tools/import_crystal_shiny_sprites.py --root .
```

Source archive titles follow `Spr 2c NNN s.png`. Generated artwork is ignored
by Git and is not covered by the mod's MIT license.
