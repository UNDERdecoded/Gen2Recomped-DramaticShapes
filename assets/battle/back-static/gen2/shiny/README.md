# Generation 2 shiny static backs

Gen 2 shiny back sprites for National Dex 001 Bulbasaur through 251 Celebi are
downloaded without resampling by:

```powershell
python tools/import_crystal_shiny_sprites.py --root .
```

Source archive titles follow `Spr b 2g NNN s.png`. Generated artwork is ignored
by Git and is not covered by the mod's MIT license.
