# Generation 4 shiny static backs

Generated for National Dex #001-#386 by
`tools/import_gen4_extended_and_shiny_sprites.py`, preferring Platinum shiny
backs and falling back to shared Diamond/Pearl files. Gender priority is bare,
male, then female. Deoxys is Speed Forme (`386S`).

Generated artwork is ignored by Git and is not covered by the mod's MIT
license. Verify that you have the right to use and distribute it.
